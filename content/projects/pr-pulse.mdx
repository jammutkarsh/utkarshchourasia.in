GitHub is good at showing one pull request at a time and poor at showing everything that
needs your attention. Checking on your PRs means opening a repository, finding Pull
Requests, opening one, going back, switching repositories and repeating, and every step
is another page load.

PR Pulse collapses that into one dashboard in your browser toolbar. It lists the pull
requests you opened and the ones waiting on your review, with checks and review status,
the diff size and the branch on each card, and it can link branch names to Jira tickets.
A background worker keeps the data fresh on an interval you choose, and you only jump
into GitHub when a pull request needs a closer look.

It is an extension, not a hosted service. Your GitHub token stays in the browser's
extension storage and data comes straight from the GitHub API, so nothing passes through
a third-party server.
