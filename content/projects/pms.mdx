Project Management ~~System~~ Sucks. I kept a dozen project folders in different places
and wanted one list to pick from instead of `cd`-ing around.

`pms add .` registers a directory, and running `pms` opens a terminal UI listing every
project you added. Filter with `/`, press enter to open the project in your default
editor, and delete one with `#`.

It is archived now because I stopped needing it, but it was a useful first project with
Bubble Tea and Cobra.
